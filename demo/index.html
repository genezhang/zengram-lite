A tiny agent with persistent memory. Tell it facts ("I use dark mode", "I drink green tea", "I'm building a Rust project") — it embeds and remembers them. Then ask questions ("what do I like?") — it recalls the relevant ones by meaning, not keywords. Fully local: the DB is Zeta compiled to wasm, and a real sentence-embedding model (all-MiniLM-L6-v2) runs in this tab.
